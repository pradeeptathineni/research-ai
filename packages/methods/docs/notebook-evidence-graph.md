# Cross-document connections

`prepareNotebookEvidenceGraph(question, notebooks, selections)` binds two to eight exact retained Notebook document pages or note versions, including the Notebook snapshot digest and the selected record and page digests. It refuses duplicate selections, missing versions, changed bindings and selections that do not span multiple documents or notes. Text is copied into an explicit bounded frozen request; this operation does not discover sources, update a Notebook or touch the Library topic store. Before dispatch or graph creation, the host must supply the validated Notebook snapshots again; Methods reconstructs the selection and refuses edited preview text even if the preview digest was recomputed.

`researchNotebookEvidenceGraph` sends only that preview's selected text to the existing mind-map research method. Every model-extracted edge has its node relationship, any exact page-local UTF-16 quote, and its full Notebook/source/document/page or note-version reference. Nodes may instead carry explicit gaps when the selected material leaves a question open. Any explicit gap marks coverage `partial`; when the model reports none, coverage remains `unknown` rather than claiming completeness. `assertNotebookEvidenceGraphEdge` adds a separate caller-asserted edge with an identified author and no source citation. Assertions never become extracted evidence.

The returned `research-notebook-evidence-graph-v1` is a portable cold-open closure. `validateNotebookEvidenceGraph` replays its source hashes, generated map, exact quote spans and assertions without a model call. `renderNotebookEvidenceGraph` emits the reopenable JSON, a list-equivalent edge projection or Markdown. `checkNotebookEvidenceGraphSources` compares only the selected record versions against supplied Notebook snapshots; a newer Notebook revision can report `notebookSnapshot: "changed"` while its unchanged selected page remains `status: "current"`.

This workflow identifies exact text occurrence and records fallible extracted relationships. It does not establish entailment, truth, source independence, source currentness or Library relevance. A cold-opened graph reports its retained snapshot; currentness requires an explicit check against current Notebook snapshots. Research Methods returns the closure to its caller and owns no graph persistence.
