# Data map

Rejected opt-in nomination metadata stays private in `rejectedCheckSuggestions`, separate from accepted offers and source evidence. It binds the unchanged answer digest and declares `parsed-final-suggestions` scope. Serializable fields retain at most 32 KiB of UTF8 JSON with a captured digest, byte count and omitted count; missing or nonserializable fields claim no payload. Replay checks this closure and rejects accepted/rejected coexistence. This is not stdout, reasoning, verified evidence or peer interchange. Original offered URL strings/order remain hashed; admission checks their safe normalized destinations against that answer's citations, retaining meaningful query/fragment identity and rejecting duplicate normalized destinations. Both raw and normalized destinations must fit the 2048 UTF16-unit request limit.

Opt-in answer-first `checkSuggestions` retains at most three ordered unverified propositions, their narrative/need basis, consequence rationale and original cited URLs. Its `answerDigest` binds the unchanged answer; `offeredDigest` hashes UTF8 JSON of ordered `[claim,basis,why,urls]` tuples. An explicit linked selection pairs `suggestionIndex` and that digest before acquisition. The child retains `suggestionDigest` over `["check-selection-v1",parentRunId,parentAnswerDigest,offeredDigest,index]`, alongside the existing receipt's actual edited proposition and source order. Replay rejects inconsistent closures without treating hashes or nomination labels as authority or support. Memory-only answers acquire no implicit parent persistence; linked checks require an existing retained parent. Old absent-field runs remain readable.

Public JSON is canonical knowledge. Local JSON is private working state. Indexes and Pages assets are disposable projections. Closed schemas reject unknown fields, duplicate keys, forged bindings, ambiguous identities and score tampering.

Active native brief v7 carries `query-relevance-v1` and `signal-strength-v10`. The entity's source-bound `signalBasis` permits deterministic type-rubric replay. Historical v0–v9 keep their declared meanings; brief v4 selects v7, v5 selects v8 and v6 selects v9. Optional bound origin inspections distinguish acquisition location, publishing venue and originating effort. Entity-level retained decisive observation IDs carry unresolved negative bindings through every refresh format without rewriting observations or old numerical policy semantics. Earlier nested basis metadata remains readable. These are internal lineage references, not model-authored fields. Current automatic admission can hold a historical receipt without changing its numerical score. Query assessment exchange validates exported source IDs against the bundle. Query relevance, priority, discovery trails, personal decisions and entity deltas never become intrinsic evidence. See the [assessment contract](../signals-contract.md).

Evidence is append-only. `excerptDigest` distinguishes projections, the declared `normalizer` binds normalized text, `currentEvidence` selects snapshots, and `currentChecks` binds actual reacquisition. New observation `identityVersion2` includes claim wording. Corrections create successor judgments; cyclic supersession and unbound/forged spans fail validation. Original dates and frozen downloads remain unchanged. Per-file atomic writes serialize through a cooperating writer lock.

Fresh HTML uses `text-v3`, an inert DOM representation with block boundaries and delimited table rows. Table section provenance records explicit cell tags, spans, scopes, header references and a logical occupancy grid. Cell offsets use UTF-16 units in the SHA256-bound normalized snapshot; DOM row/cell ordinals and generated row/column separators are separate from original source wording and raw byte offsets. Cache replay validates the projection digest, enclosing text and cell spans, and occupancy. This geometry lives in document material/cache, while entity and claim receipts preserve their own text/excerpt closures. They do not export the complete grid. The HTML document digest hashes the UTF8 encoding of the decoded response string. Explicit hidden/navigation/script noise is excluded and counted; computed CSS is not evaluated. Unsupported/deep/oversized structures report omissions rather than inferred associations. Claim checks decline truncated material. Known `text-v2` receipts keep their original decoder, IDs, quotes and dates. Fresh acquisition bypasses old HTML caches without deleting them, and a legacy-representation 304 requires a body rather than establishing unchanged representation or renewed claims. Changed later bodies can advance across known representation versions; an unchanged body cannot rewind its decoder. Transport equality cannot establish independent developments or factual currentness.

## Private state

Optional research diagnostics describe only events the runner received. Provider `actionCounts.messages` partitions completed agent messages into checkpointed, unreadable, duplicate, limited, after-stop and schema-excluded categories. Checkpointed means accepted into the interim note buffer, not necessarily stored in the final result: a final answer replaces interim notes, and the existing cap can shorten them with an omission marker. These counts do not recover excluded text, count unseen provider output or measure semantic completeness. Stopped research may record `usage.stop.reason` as deadline, external or unknown (`null`), with a monotonic duration beside existing wall timing. Neither clock measures CPU work or user effort, and platform suspend behavior can differ. Historical missing diagnostics remain unknown and are not backfilled. Narrative/citation bindings, authority, caps and private/memory retention are unchanged.

HTML material may also record bounded excluded DOM-content and inert JSON-script text counts in normalized UTF16 units. These measure exclusions, not actual browser visibility or whether the missing words are decisive. Accessibility-marked code can still be displayed. Missing historical counters remain unmeasured, while measured zero does not prove semantic completeness. Research gaps and frozen claim/review inputs disclose this extraction scope before source-based interpretation. Hidden and script text remains excluded, without execution or a larger evidence limit. Existing normalized bytes, representation versions, table geometry and historical receipts retain their meanings.

An optional linked `claimCheck` inside a private run contains exact proposition/parent digests and one or two indexed primary-material outcomes. Usable text is limited to 48,000 combined UTF-16 units and retained with its own SHA256, distinct from original document lineage. Explicit historical excerpts preserve original dates and scope; their captured closure remains readable if the origin's temporary run expires. Replay binds the source identifier to its document and snapshot digests. Unverified historical final identities remain unusable. Source denials/whole-document omissions and cancelled review remain separate from semantic verdicts. Parsed rejected replies have a bounded UTF8 diagnostic prefix with captured-byte counts. Wire overflow uses optional `captureScope:"runner-stdout"`: received-byte counts and SHA256 only, empty diagnostic text, all captured bytes omitted and `captureComplete:false`. Unclassified reasoning/tool text is never retained as that diagnostic. Run serialization and replay retain the existing two-million-byte ceiling. Memory mode writes no receipt or source cache, including when automatic saving is enabled; unscored claim checks are excluded from automatic entity saving.

Direct checks use a closed version-2 `claimCheck` with `origin.kind:"request"` and no answer-parent fields. Its `requestDigest` hashes the UTF8 JSON of the fixed ordered tuple `["direct-source-v1", query, context, claimText, normalizedOrderedTargets]`. This binds semantic request bytes, not an approval signature or acquisition controls. Direct requests require quick profile and no entity saving or enrichment. They do not accept historical references or broader source settings. The shared material, response and output limits remain, with bounded origin overhead included in the serialization reserve. Valid private direct checks survive ordinary temporary-run cleanup, while memory mode retains nothing. Version-1 linked receipts and their original parent/citation validation remain unchanged.

All of `.signals/` is ignored, excluded from public assets and denied by local/static serving. Public admission additionally rejects private bytes. Private history may retain source text containing credential-shaped documentation placeholders; structure, identity and evidence bindings still validate.

Format/destination-qualified Library keys prevent native/historical or public/private collisions. Meaning matching hydrates original records and changes no evidence or intrinsic scores. Automatic private-saving receipts retain item-level admission/exclusion reasons. No-save memory mode bypasses private persistence.

Answer-first runs add an `answerReceipt` with exact narrative SHA256, observation time, unassessed state, Unknown confidence and requested/served model provenance (unknown stays null). A separate assessment run may carry `assessmentOf` and `assessmentTargets`; capture targets must belong to the original answer's retained citation references. Targets record an attempted check, not verified success, and the workbench can reopen the original answer. `answer:private:<runId>` Library records index complete answer text locally and reopen immutable runs or legacy query imports without migrating them. Public projections exclude these records. Remote meaning-match metadata excludes their narrative text. Temporary-run cleanup preserves answer receipts and their linked assessments, including negative or incomplete checks; complete-answer discussion has an explicit bounded selection and reports omitted whole records.

Saved-context follow-ups are answer runs with an additional closed `followupOf`: exact parent ref, parent question/status, request digest, the copied frozen material/context/prior synthesis/gaps, its SHA256 and cited observation IDs. They have no items, sources, searches or documents, survive cleanup as answers and stay readable when the parent is gone.

Project source basis, editable context and decisions are distinct from entity evidence. History retains each context before edit, refresh or disconnect, up to 64 entries per project; a full history rejects further changes rather than dropping context. Context imports retain original objects/digests without inferred admission. Context v3 requests preserve namespaced opportunity IDs and enforce separate text/count/byte limits; omitted references remain local and are counted.

Batch plans freeze compatible acquisition scopes; each interest retains separate assessment. Interrupted running questions become uncertain rather than being automatically repeated. Source access failure preserves the last successful material. Source health counts acquisition scans separately from result exposures; missing historical provenance does not create feedback credit.

There are no SQL tables, ORM mirrors, database destinations or database-history commands.
Useful retired exports and implementation receipts belong in private planning archives,
with original paths and verified hashes for recovery. Public historical records still
use their declared decoding and assessment policies. [Product intent](../product.yaml)
and [AI authoring context](../../.meta/context/README.md) describe the project rather than public evidence.

Selected-primary checks use a closed version-4 private receipt, distinct from historical citations and complete HTML normalization. Creation requires a host-installed registered producer; default API/CLI requests cannot supply evidence bytes, paths or producer objects. The host verifies the captured PDF identity and replays the accepted offline selector against a bounded full normalized extraction. No PDF parser or acquisition is installed by this contract.

The receipt binds request/proposition/ordered target/packet digest and a selected-page-windows material closure. Original PDF, full normalized text, extraction bytes, selected packet and generated display-view digests remain distinct. Exact quotes must occur inside one selected window and retain original global UTF16/page occurrences. Unread and unextracted material may contain contrary conditions. Completed scoped review remains overall partial, Confidence Unknown and no Signal.

Private v4 history explicitly copies up to 250,000 UTF8 extraction bytes as base64 for self-contained deep page/selection replay; it does not copy the raw PDF or send the full archive to the reviewer. Deleting an external artifact does not delete this independent copy. Memory mode writes none. Native selected-source JSON stays within 48,000 UTF16 units; private serialization stays within two million bytes. Disabling v4 creation preserves reading, and versions 1–3 keep their existing contracts. This producer-only path adds no public upload, file selector, default PDF support or historical-parent authority.
